First release. Cleaning Mode locks your keyboard so you can wipe it clean.

- Click the keyboard icon in the menu bar, pick 30 s to 5 min, click **Start Cleaning**.
- Blocks every key, including modifiers, Fn, the function row, and the media and brightness keys. The mouse and the trackpad keep working.
- A dark full-screen cover shows a countdown and how many presses it blocked. Click **Done** or let the timer run out.
- Puts Caps Lock back as it was. Records nothing. No network connections.

**Install:** download `Cleaning-Mode.zip`, unzip, move the app to Applications. This build is not notarized: on first open, go to **System Settings › Privacy & Security** and click **Open Anyway**. Then allow Accessibility access when the app asks.

Requires macOS 14 or later. Universal (Apple silicon and Intel).
